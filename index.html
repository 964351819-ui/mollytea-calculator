1. 快速上手

这个工具用于估算美团、淘宝闪购在直营与代理口径下的商家到手价、到手率和毛利表现。建议先完成一笔单品测算，再加入汇总列表进行横向比较。

1填写订单输入外卖原价、打包费、折扣、距离和时段；成本类字段按需填写。
2选择活动勾选神会员、爆红包或减配；标准档位自动匹配，自定义档位可手填。
3查看与汇总核对平台费用明细，点击“加入汇总列表”，比较多产品与多渠道结果。
最少必填：外卖原价与打包费。若要看毛利，请继续填写产品成本；如包含周边物料，再填写周边订货价。

2. 输入字段怎么填

字段用途填写建议
产品名称区分商品、套餐或规格。建议使用“产品名＋规格/组合”，便于汇总和导出后识别。
外卖原价折扣、活动门槛、到手和平台费用的核心价格。填写外卖端展示原价，不是折后价。
堂食原价用于展示堂食实付及外卖/堂食价格对照。不参与平台佣金和到手价计算。
打包费计入订单金额、活动门槛与到手率分母。必填；没有打包费时填写 0。
产品成本用于毛利和毛利率计算。填写该商品的直接产品成本。
周边订货价作为额外成本计入毛利。套餐含杯套、冰箱贴等周边时填写；无则留空。
折扣 / 折后价两种输入方式可切换，系统最终统一换算为折扣率。折扣支持 0.85、8.5、85 三种写法；折后价不得高于外卖原价。
配送距离 / 时段决定不同平台和渠道的配送加价。按实际预估配送半径与下单时段选择。
淘宝直营技术费率淘宝直营技术服务费的城市差异参数。默认 7%，支持小数；实际因城、因店可能不同。

3. 核心计算口径

以下公式中的“原价”均指外卖原价，“活动商家出资”包含神会员/爆红包商家出资与减配，不包含平台补贴。

成交价 = 外卖原价 × 折扣
折扣出资 = 外卖原价 − 成交价
订单总额 = 外卖原价 + 打包费
扣费基数 = 订单总额 − 折扣出资 − 活动商家出资
= 成交价 + 打包费 − 活动商家出资
到手价 = 扣费基数 − 技术/运营服务费 − 配送费
展示到手率 = 到手价 ÷（外卖原价 + 打包费）
直营/代理综合：完整版平台结果按直营 60%＋代理 40%加权展示；汇总版同时选择直营和代理时，不再合成一行，而是直营产品统一列在上方、代理产品统一列在下方。

4. 平台费用完整逻辑

美团直营

技术服务费 = max（扣费基数 × 6%，1.3 元）
距离加价 = max（配送距离 − 2.5km，0）× 1.1 元
客单加价 = max（扣费基数 − 30 元，0）× 8%
配送费 = 3 元 + 距离加价 + 客单加价 + 时段加价
直营到手 = 扣费基数 − 技术服务费 − 配送费

美团代理

技术服务费 =（外卖原价 + 打包费）× 1%
运营服务费 = max〔（外卖原价 + 打包费）× 9%，1.5 元〕
距离加价 = min〔max（距离−2.5，0），2.5〕×0.7 + max（距离−5，0）×1.2
客单加价 = min〔max（订单总额−20，0）×10%，50 元〕
折后配送费 =（3.5 元 + 距离加价 + 客单加价 + 时段加价）× 66%
实际配送费 = min（折后配送费，扣费基数 × 40%）
代理到手 = 扣费基数 − 技术服务费 − 运营服务费 − 实际配送费

淘宝闪购直营

技术服务费 = 扣费基数 × 自定义费率（默认 7%）× 75%，不设 1.55 元保底
距离加价 = max（配送距离 − 3km，0）× 0.6 元
25–50 元客单部分：每满 5 元加 0.6 元；50 元以上部分：每满 5 元加 0.8 元
配送费 =（3.5 元 + 距离加价 + 客单加价 + 时段加价）× 75%
直营到手 = 扣费基数 − 技术服务费 − 配送费

淘宝闪购代理

运营服务费（全包）=（外卖原价 + 打包费）× 18%
代理到手 = 扣费基数 − 运营服务费

5. 活动、补贴与自动档位

标准档位会按照平台的活动门槛金额自动跳转；选择“自定义”后，出资和补贴清空并允许手动填写，不再自动覆盖。

活动门槛金额 = 外卖原价 × 对应平台折扣 + 打包费
商家活动成本 = 折扣出资 + 神会员/爆红包商家出资 + 减配出资
平台补贴不计入商家活动成本，但会用于计算消费者外卖实付。减配只影响商家到手，不从消费者实付中再次扣除。

6. 实付、毛利与毛利率

外卖实付 = 外卖原价 + 打包费 − 折扣出资 − 神会员/爆红包商家出资 − 平台补贴
堂食实付 = 堂食原价
毛利 = 到手价 − 产品成本 − 周边订货价
毛利率 = 毛利 ÷ 到手价

产品成本或周边订货价未填写时，对应字段按 0 参与毛利计算；若两者均未填写，建议不要将毛利结果用于经营判断。

7. 汇总版怎么用

  • 快速测算：在汇总版顶部直接录入，与完整版共用同一套计算逻辑；点击“加入汇总列表”生成产品行。
  • 测算校验：汇总版右上角会实时显示问题数量；点击后集中查看阻断问题与复核提醒。
  • 渠道字段：可选美团、淘宝、直营、代理。多产品同时选择直营和代理时，直营统一在上、代理统一在下。
  • 经营字段：按需要显示或隐藏列；配送距离、时段和打包费默认隐藏，可随时打开。
  • 直接编辑：双击可编辑字段即可修改，结果会立即重算；点击活动、佣金或到手价后的信息图标查看明细。
  • 排序与复制：支持调整产品顺序和列顺序；复制表格会包含当前显示列及“直营/代理”渠道口径。
  • 平均行：分别展示直营和代理的平均结果，便于横向判断。

推荐工作流

  1. 在完整版建立标准参数；产品较多时下载模板并批量导入。
  2. 在汇总版运行“测算校验”，先修正阻断问题，再处理复核提醒。
  3. 将确认中的清单保存为方案，调整价格、折扣或活动后在项目夹进行对比。
  4. 确认方案后存入项目夹，复制业务表格或导出分析表格。

9. 数据保存、分享与导出

  • 本地保存：输入、产品清单、项目夹、方案、主题和布局保存在当前浏览器本机，不会自动上传。
  • 批量导入：CSV/TSV 可离线读取；XLSX/XLS 需要联网加载 Excel 解析组件。导入前会先预览，确认后才追加。
  • 方案记录：从项目夹进入方案对比；保存产品清单、平台和渠道口径，可随时恢复，对比结果同时标记当前计算版本。
  • 发送原 HTML：接收者得到的是发送当时的文件版本；你以后继续修改自己的文件，对方不会自动更新。
  • 导出分享版：会绑定导出时的主题色和当前自定义背景，接收者直接打开即可看到相同视觉。
  • 复制表格：输出制表符格式，可直接粘贴到 Excel、飞书表格等工具。
  • 分析表格：输出 XLSX，包含明细、汇总、平台对比、标签和经营诊断等分析内容。
  • 项目夹：保存的是当前清单快照；每个项目的显示列和渠道选择独立，不应影响其他项目。
  • 口径版本：工具底部及本说明书最下方显示当前版本。以后调整费率、档位、公式或功能时，说明书与更新记录必须同步修改。

10. 使用提醒

  • 结果用于方案预估和内部比较，不替代平台账单结算。
  • 淘宝直营技术服务费因城定价，默认 7% 仅为工具预设，请按当地实际政策修改。
  • 平台费率、活动档位、配送规则发生变化时，应先更新工具口径再批量测算。
  • 输入负数、折后价高于原价或缺少打包费会导致结果失真；打包费为 0 时也应明确填写 0。
  • 比较产品时，请确保距离、时段、活动与渠道口径一致。
  • 毛利只扣除了产品成本与周边订货价，未包含房租、人工、水电、损耗、税费等经营费用。
建议复核顺序：先核对价格与折扣 → 再核对活动出资/补贴 → 再看平台费用明细 → 最后判断到手率和毛利率。
